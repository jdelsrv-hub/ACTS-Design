# Creator Security Checklist

**All Creative Technology Solutions (acTS)** · From the Creator Security Pack v1.0 · Checked 23 October 2026

Print this page and tick it off. Redo it every six months, and any time you change phones. The full steps for each line are in the pack.

**Lock down your accounts**

- [ ] Main email secured first: unique password and two-step login
- [ ] Password manager set up; main password on paper at home
- [ ] Every account has its own password
- [ ] Passkeys added where offered
- [ ] Two-step login on everywhere, using an app, key or passkey over SMS
- [ ] Extra protection on your mobile number
- [ ] Backup codes printed and stored safely, not in your email
- [ ] Recovery email and phone up to date
- [ ] Unknown devices signed out; unused apps removed

**Your team**

- [ ] No shared passwords
- [ ] Helpers on their own access, lowest role that works
- [ ] Team list reviewed every three months

**Scams**

- [ ] Never download "contracts", media kits or games from unchecked brands
- [ ] Check deals through the brand's real website
- [ ] Strike or deadline message? Check in the app, never the link
- [ ] Never pay to be sponsored; never share codes

**Doxxing**

- [ ] Camera location off on every phone in the house
- [ ] Check windows, parcels, reflections and uniforms before posting
- [ ] Business email and number; PO Box or Parcel Locker
- [ ] Domain privacy on
- [ ] Post locations after you've left

**Streaming**

- [ ] Window Capture, not Display Capture
- [ ] Privacy scene with a hotkey; stream delay on
- [ ] Streaming-only browser profile, no autofill
- [ ] Do Not Disturb on; stream key never on screen

**If you're hacked**

- [ ] Clean device, then email first, then official recovery links
- [ ] Sign out everywhere; remove what the scammer added
- [ ] Bank, followers, brand partners told; reports made
