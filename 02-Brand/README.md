# acTS Brand Kit

**All Creative Technology Solutions (acTS)** · Sydney, NSW · Version 1.0 (draft, 2026-10-19)

## For any Claude agent (or person) using this kit

Read these files in order before you write, design or reply to anything on behalf of acTS:

1. `01-brand-core.md`: who we are, who we serve, what we promise
2. `02-voice-and-tone.md`: how we sound, words to use and avoid, before/after examples
3. `03-visual-identity.md`: logo, colours (with hex codes), fonts, imagery, layout
4. `04-copy-library.md`: approved taglines, bios, service blurbs and message templates
5. `05-brand-checklist.md`: run every output through this before it goes out

`brand-preview.html` shows the logo, colours and type together. Open it in any browser.

## The brand in five lines

- **Name:** All Creative Technology Solutions, shortened to **acTS** (lowercase "ac", uppercase "TS").
- **Personality:** a calm expert with a bold streak. Easy, useful, intuitive.
- **Voice:** casual and Aussie, always kind, with big-brand polish. We speak as a small studio: "we".
- **Look:** dark studio purples with bright signal green. Clean, modern, creator-tech.
- **Promise:** creators feel supported and heard. If we can't help, we'll find who can.

## Rules of precedence

If two files disagree, the more specific file wins (for example, the checklist over the core). If something isn't covered, choose the option that is easiest for the creator to understand, then flag it to Jess so the kit can be updated.
