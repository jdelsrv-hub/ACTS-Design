# acTS: All Creative Technology Solutions

Sydney, NSW business run by Jess with Claude. ACTS handles the tech side for content creators (setup builds, clipping, safety and security packs, ads, analytics) so they can focus on the creative side.

**For any Claude agent working here:** read this file first, then `02-Brand/README.md` before writing anything customer-facing, and follow the brand files exactly.

## Folders

| Folder | What goes in it |
| --- | --- |
| `01-Plan/` | The business plan and model. The live, editable version is the Claude Doc "ACTS Business Plan": https://claude.ai/code/artifact/8d918149-26d9-41a5-a8d5-06a343b31e51. Also holds the [website to-do list](01-Plan/2026-10-19%20Website%20to-do%20list.md) and the [dashboard and tools plan](01-Plan/2026-10-20%20Dashboard%20and%20tools%20plan.md) for the logged-in creator app, and the [income empire plan](01-Plan/2026-10-23%20Income%20empire%20plan.md) (income streams and the `empire-*` agents). |
| `02-Brand/` | Brand definition: personality, voice, words to use and avoid, colours, fonts, example copy (step 3) |
| `03-Services/` | Service descriptions, pricing sheets, safety and security packs, setup guides |
| `04-Clients/` | One subfolder per client: briefs, agreements, delivered work |
| `05-Finance/` | Financial model, invoices, expenses. `Empire/` holds the income scoreboard (`streams.md`), the ledger and an `inbox/` for sales and ad exports |
| `06-Admin-Legal/` | ABN, business name, insurance, terms of service |
| `07-Research/` | Market research; `Creator-Feedback/` holds family creators' answers |
| `08-Website/` | The website: `site/index.html` is the full one-page site, `README.md` lists what is still a placeholder |
| `Assets/` | `Images/`, `Logos/`, `Recordings/`, `Video/` |
